2. CORE PRODUCT IDEA
SAHAYAK must NOT simply answer:
"Is this person stressed?"
Instead, it should answer:
"What is normal for this person, what has changed, what factors may be contributing to the change, is the change persistent, what support or intervention could help, and did the person's condition move back toward their normal baseline afterward?"

8. OFFLINE-FIRST RULE
For every user action, determine:
Can this action work offline?
If yes:
Save locally.
Mark as pending synchronization.
Update UI immediately.
Queue synchronization.
Synchronize when connectivity returns.
Example:
User completes Quick Tap
        ↓
Result saved to SQLite
        ↓
UI displays completion immediately
        ↓
sync_status = pending
        ↓
Internet becomes available
        ↓
Upload to Supabase
        ↓
sync_status = synced
Never force the user to wait for the server to complete a simple offline-capable action.
